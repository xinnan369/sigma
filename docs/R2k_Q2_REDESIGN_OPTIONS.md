# Q1-v2 候选设计与独立验收条件

以下是待验收的方案。任何训练、超参数比较、GPU 或新数据采集均为 NOT RUN。现有 Q1 Holdout 仅保留为历史诊断；后续实现只能在原 Fit/Calibration 图像上确定特征、模型和操作点。先批准并冻结配置、候选数、评价代码与判据，再采集和打开独立数据。

## 候选 1：频带比值与局部边缘证据

**失败机制。** 六个单尺度描述把模糊造成的梯度下降与健康低纹理混在一起。利用同一局部区域中不同尺度的边缘扩散和高频相对低频能量，可以区分边缘变宽与纯低对比度的部分情形。

**设计。** 预先固定小、中、大三个尺度的邻域。计算保留粗尺度边缘时的细／粗梯度比、带通高频与中频能量比、局部边缘宽度、局部近常数／饱和程度与细尺度噪声残差。分别输出健康、噪声、遮挡、模糊的概率，质量由合并的退化概率定义。将低纹理健康块作为明确的训练硬负例。若粗尺度本身几乎无边缘，允许输出低可辨识性标志并保留完整报告，不能将未知位置从主指标删掉。单帧完全平坦块可能本质不可辨识。

**监督与对照。** 用原 Fit/Calibration 上同图健康和合成退化构造配对监督。排序目标只在合成区域及有可观测变化的预定义子层分别报告，不能把它等同于语义可用性。设置同维同参数的当前六特征／新增频带消融、RGB-only 同算子输入、方差／梯度单特征、常数与标签置乱。图像解码、分辨率、算子计数和训练预算需对齐，昂贵卷积通过配对测量单列。为避免将 RGB 语义当质量，应在同一 RGB 下替换 Thermal，并直接比较同夜/昼、同纹理强度的配对分数变化。RGB 设置对照与训练标签配对，但健康／退化两视图的 RGB 输入严格相同。

## 候选 2：按退化类型建模，并显式区分变化与可辨识性

**失败机制。** 合成 ROI 混合可见变化、轻微变化及零变化。噪声、遮挡与模糊可以在纹理空间朝相反方向移动。单一方向的 bad logit 容易把未见模糊推向健康端。

**设计。** 使用固定多尺度频带残差、平坦区高频异常能量、阶跃边缘宽度和饱和／均匀填充比例。共享浅层特征头，以三种退化的独立分量输出和显式可辨识性输出建模。Fit 中用同图两视图计算局部变化幅度或已知外加严重度，训练退化分量与可见性，但推理只使用当前 Thermal。变化监督来自图像对，不能在评价时输入健康图、ROI、退化 ID 或该图的差分。对健康低纹理和安静夜间区域保留独立负例。校准连续概率并按有效信息不足单列结果，完整集的缺失或弃权仍计入覆盖和召回。

**监督与对照。** 成对变化量只是可见性信号，健康/退化标签与族标签才用来解释监督含义。用同深度、同参数、同特征计算的单输出头比较多分量目标。匹配 Thermal-only 与灰度 RGB-only，加入同昼夜跨场景错配 Thermal 分量控制。另设共享头但去掉可见性监督的同预算对照。冻结同组配对和位置随机化，避免根据 RGB 内容代理或稀有物体直接认定故障。关键风险包括配对标注偏向可见伪影，以及实时未知失真不一定落在训练的三个输出族内。

## 新数据与预先定义的判据

独立数据来源建议是另行采集、从未参与 R1g/Q1 的新地点 RGB-T 配对序列。覆盖白天、夜间、不同目标和低纹理背景。按采集序列与场景分组，同地点近邻帧不得跨区，核验硬件与时段元数据及近重复。预先规划至少 40 个独立场景组、每时段至少 15 组。每种退化上至少 15 个有正例的组。采集配对的健康与受控真实失焦／遮挡／噪声，记录独立的处理或传感器状态作为评价标签。合成强度阶也可以作为另一个固定压力测试，并单独报告。采集渠道和许可待确认；当前没有已批准的独立验收数据。

多族辨识与未见族泛化必须分开。前者可在现有 Fit/Calibration 上学习三族，并在新采集的三个退化族分别评估。后者按整个族留出，健康操作点只能来自其余训练族以及 Calibration。若拟合或阈值选择接触了 Blur，则该模型在独立数据上的 Blur 结果只说明跨场景或协议迁移。要声称未见族泛化，须为该族执行完整留族方案。

以下规则须在新数据取得前经独立验收后冻结：

- **PASS**。在预指定留族主比较中，对 RGB-only 同预算控制的配对 AUPRC 区间下界大于零，平衡 Brier 的差值区间上界小于零。健康总体 FPR 不超过 7%，昼夜及低纹理分层均不超过 10%。在 Calibration 固定的操作点，留族召回至少 20%，且同图 Thermal 替换使损伤分数沿预期方向变化。已见三族辨识分别披露，单一强项不能冲抵留族失败。
- **FAIL**。支持充足时，明显逆向的主要差值、固定误报守门或召回守门未通过、错配或 RGB-only 同等／更好且其区间支持，均停止推进。设计漏读保护、参考输入泄漏或组泄漏属于工程失败。
- **INCONCLUSIVE**。达不到冻结组支持，或主比较区间跨越零且其余守门达到时，保留结果等待新的独立证据。视觉或采集组配对 Bootstrap 固定 10,000 次，同组权重跨模型共享；弃权视图保留在分母。一次性评估后不能用该数据改模型并再次称之为确认性验收。

优先从候选 1 开始进行未来 CPU 可行性评审。只有控制消融能区分频带证据与普通容量，才考虑候选 2 的额外监督。两者均不进入分割流程。
