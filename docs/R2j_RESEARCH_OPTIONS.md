# R2j 候选研究方案

本文件只提出设计和待验收的预算。训练、GPU 推理、超参数搜索和官方 test 评估均为 NOT RUN。

## 1. 带独立校准任务的 Thermal 质量估计

**假设。** 一个在训练侧冻结成对退化上学习的质量估计，可以识别受损的 Thermal 信息，并且在遇到未参与训练的退化类型时，比 RGB-only 或错配质量信号更有效地降低 ROI 外真实错误。估计目标是局部传感退化概率，语义有用性作为下游独立验证目标。

**机制。** 仅从当前单帧 Thermal 邻域估计局部质量。可预先限定饱和比例、梯度能量与局部动态范围的固定描述，再用轻量预测头输出质量。训练可使用同一图像的健康/退化配对监督，推理只从实际 Thermal 计算，无需提供合成 ROI、Clean 对照或类别标签。以接近 1 的默认质量乘到跨模态注入接口，低质量仅抑制 Thermal，RGB 直通。先在训练集内部冻结分组上估计校准与迁移质量，防止把目标或夜间纹理当作异常。所有候选共享训练预算、随机流及增强样本，主终点继续使用同条件 ROI 外净错误和 Clean 非劣性。

**控制。** 原始 Sigma、参数与算子同形的 RGB-only 评分控制，以及同一已训练头的跨组错配质量图测试。错配必须匹配天/夜、保持质量图边际分布、完整记录配对。输入不同模态时仍执行相同的算子图，报告总参数、额外算术、推理时延和占用。预先比较有监督质量头和匹配控制的校准判据。令训练与验证的退化实例和一类退化家族完全分离。

**失败条件。** 若未见退化家族上的配对识别优势区间不能排除零，停止。即使校准改善，若门控无法比等容量或错配控制减少净错误，或者 Clean 两种 mIoU 的下界不能通过 0.5 pp 比较，停止扩展。单阶段早停只表示筛查未过。合成退化可能比真实传感故障容易识别；RGB 可能同样受损，且低纹理也可能是有效背景。

**新颖性。** Sigma 通过 Cross-Mamba 的跨模态信息交换及 Concat-Mamba 的融合实现共享表示。RSGMamba 已设计模态不确定性和跨模态一致性门控，CMX 也已用对侧模态校正特征。潜在差异在于把 Sensor 质量的可迁移校准、同预算代理与错配干预作为可证伪的证据链。独立监督和门控本身有广泛先例，不能仅据模块名称主张创新。 [Sigma](https://openaccess.thecvf.com/content/WACV2025/html/Wan_Sigma_Siamese_Mamba_Network_for_Multi-Modal_Semantic_Segmentation_WACV_2025_paper.html) · [RSGMamba，arXiv v1](https://arxiv.org/html/2604.12319v1) · [CMX](https://arxiv.org/abs/2203.04838)

**最小 GPU 预算。** 先做 CPU 合成测试和训练侧校准可行性。通过后只用 3407、一个增强轨道，原始、质量头、RGB-only 三组各 1 Epoch、157 更新，按 R2i-S2 实测约 0.47 GPU 小时训练，另预留 0.13 小时评估与性能测量，合计约 0.60 小时。预算为推算。未达筛查条件便停止；即便通过也仅提交后续独立验收。

## 2. 将同一质量图用于状态注入与读出位置对照

**假设。** 对未来可用的质量图，在状态递推前按位置衰减 Thermal 的写入项，可比仅调节读出更好地限制异常信息的远程传播，并减少真实错误。R2g 的 D*x 路径也有显著响应，因此仅抑制状态写入可能无法覆盖主要误差源。

**机制。** 保留 RGB 和自身状态的原有路径，仅在可明确追溯为 Thermal 的选择性扫描注入处给离散输入项乘质量因子，形式为 h_t = Ā_t h_{t−1} + B̄_t (q_t x_t)。作用点固定在直接残差分支之后或分流处，D*x 保持原值，A、Δ、C 维持原模型计算。采用 R2f 的精确扫描映射和基向量验证，q=1 必须通过原生 CUDA 数值与 Identity 闸门。逐方向注入分量不得通过张量形状猜测，必须先核查 Sigma 的 Cross/Concat 路径和 Native CUDA 接口。q 作为一张可观测质量图，不能直接用真实评估 ROI。若相同 q 在 A/B/C 生成后无法隔离到所需的输入项，工程闸门停止。

**控制。** 对同一冻结 checkpoint、同一质量图和同一读出算术预算做成对比较，包括 Identity、写入衰减、读出衰减及错配质量图。写入和读出皆使用同一质量估计、同样的逐位置乘法，并分别报告 CUDA 路径成本和峰值。D*x-only 干预可用作后续定位对照，因为它解释了部分 R2g 响应。保持 Clean 非劣性闸门，报告 ROI 外新增、纠正、净错误和距离带，避免把预测变稳定当作分割变准确。

**失败条件。** q=1 数值审计失败、注入点无法确认、缺陷未进入目标状态分支、写入相对读出或错配无法减少净错误，或收益仅体现为降低分歧，均停止。冻结权重干预结果只评估该操作在固定模型内的证据，训练后比较须另行验收。质量识别不稳、长程传播经共享编码器或直接项绕过，以及局部受损掩盖真实热源，都是具体风险。

**新颖性。** RSGMamba 在读出阶段进行跨状态融合并动态调节读出。本方案以同一质量图和预算对比写入 vs 读出，结合方向定位和错配控制检验机制。值得主张的增量是干预位置的可重复差异，前提是其在真实错误上成立。用可靠性调节特征或状态空间本身已有先例。 [Sigma](https://openaccess.thecvf.com/content/WACV2025/html/Wan_Sigma_Siamese_Mamba_Network_for_Multi-Modal_Semantic_Segmentation_WACV_2025_paper.html) · [RSGMamba，第 III 节](https://arxiv.org/html/2604.12319v1)

**最小 GPU 预算。** 只有质量信号通过候选 1 的可迁移校准后，先在 CPU 检查短序列递推，再申请单个冻结 SSM checkpoint 的 12 张固定图工程 Pilot。限制一组预固定编码器路径、自然 Clean/Corrupt 和四个控制回放。按 R2h 的同量级三架构 Pilot 约 586 秒估算，可申请最高 0.25 GPU 小时（15 分钟），不训练。超时或数值错误就停。12 图无法确认收益，全面比较需要单独验收。
