# R3-D0：LLVIP RGB-T 行人检测预注册 v1

R3-D0 只审计数据和 CPU 工程。后续阶段需独立授权；官方 test 不用于任何模型、阈值、增强、参数量或 Epoch 选择。冻结 development manifest 后，使用验证集选择 checkpoint；在获批打开官方 test 前锁定模型、预处理、评分脚本、权重与 SHA256。此前 Q1v2 两次用同一 64 张 test 做质量头探索，即便没有检测选型，也不能把完整 test 称作未见盲测。未来允许评价时同时报告完整官方 split 和去除这 64 张后的敏感性结果；不得用后者替代官方指标或称其已证独立。七个 UNKNOWN 候选需先审查，官方 split 不被重写。

## 输入和坐标

以发布版 1280×1024 对齐图像为基础，RGB 解码为 RGB、Thermal 通过 OpenCV BGR 转单通道灰度（不声称是原传感器辐射值）。两路使用同一轴向缩放 0.5、INTER_AREA 到 640×512，上下各 pad 64（值 114），共同形成 640×640；不裁视野。输入 float32 /255，无数据依赖曝光调节。训练若启用水平翻转，同一率 0.5，以样本 ID/训练 seed/epoch 派生一次并应用于两模态与框；验证及测试不翻转。VOC 坐标按作者转换器宽度 xmax−xmin、高度 ymax−ymin，冻结使用连续边界 xyxy，不加一、不猜测零宽的真实边缘。正向 x'=0.5x、y'=0.5y+64；翻转 x0'=640−x1、x1'=640−x0（在输入网格）。预测从非翻转布局逆映射，在原尺寸剪裁，移除逆映射后面积为零的预测。保留 XML difficult 元数据；单类 person 的主 COCO 评估将所有有效 person 框均作为常规非 crowd GT（不套 VOC difficult 忽略规则），两种规则不得混报。异常框所在训练图整帧隔离，不把未标目标当背景；不修改 XML。

## 四组独立对照

| 组 | 模态与融合 |
|---|---|
| RGB-only | 仅 RGB 通路；不得输入 Thermal 或故障信息 |
| Thermal-only | 仅 Thermal 通路；不得输入 RGB |
| 普通融合 | 两路同构编码器，在固定尺度按通道拼接后用轻量局部卷积混合 |
| 等预算 Mamba/SSM 融合 | 两路同构编码器及相同融合位置，以 SSM 扫描混合替换普通融合；保持检测 neck/head 一致 |

普通与 SSM 对照除融合外共享结构、损失、输入、训练集、采样顺序、步数、优化器和验证选模标准；对应公共层使用相同初值，各自独立训练。预先使用静态结构和 dummy input 选融合内部宽度，使全模型参数差 ≤1%、端到端 MAC 差 ≤5%；必须报告算子计数覆盖，无法确认时不得宣称计算匹配，若参数差超限就先修可行性，不开正式训练。单模态对照给出各自真实成本，不声称与双路严格等参。正式执行前须另行冻结精确版本、总步数、随机种子、优化器及预算；禁止用检测性能决定宽度。

## 冻结指标

主检测指标：person 类 COCO bbox mAP@0.5 与 mAP@0.5:0.95（IoU 步长 0.05，101 点，maxDets=100），统一冻结 evaluator 版本、置信输出保留策略与 NMS（IoU 0.65、不另设分数过滤、每图最多 100 个 NMS 后框）。同预算主要比较为 SSM−普通融合。报告总参数与可训练参数、MAC，以及同设备 FP32 单图延迟（batch=1，20 次预热、100 次测量，同步计时，分别报告模型和含预处理/NMS 的端到端中位/P95；对应设备与软件版本盲于模型效果预先锁定）。

合成退化作为固定次要指标：在验证和将来另行获准的 test 上，分别测 Thermal-only 中心 64×64 原网格遮挡（fill=0）、中心 64×64 Gaussian σ20 像素噪声（8-bit clip、按 SHA256 派生 PCG64 seed=3407+ID 命名，准确串为 3407/<id>/noise，取摘要前 8 字节大端整数；四舍五入取最近偶数）以及同区域 Gaussian 模糊（17×17、σ4，全帧滤波后仅粘贴 ROI）；中心左上按 (W−64)/2,(H−64)/2。几何、GT、RGB 均不变，另含逐预测一致的 identity 对照。分别报告两项 AP、相对 clean 的绝对百分点变化；测试不调参数。衍生处理权限未核实前仅允许无真实图像的合成单测。可能评估场景聚类时以冻结代理组为单位，不把帧当独立样本；不宣称当前 split 可证明跨场景泛化。
