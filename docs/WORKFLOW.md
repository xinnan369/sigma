# 协作及合并规则（2026-11-04）

- **ChatGPT**：文献/科学问题、任务定义、审查 PR 与报告，形成 `PASS` 或 `FAIL`。
- **Codex**：代码实现、测试、实验、报告、PR；通过验收后负责合并。
- **用户**：提供运行环境、启动 Codex；不需要逐项审批已通过验收的 PR。

## 合并门槛
1. PR 的最后 commit SHA 与审核时一致。
2. 任务验收项全部通过，且测试结果有实际日志证明。
3. 无数据、模型权重、密钥或不可审计的大文件；无未经标注的上游大段复制。
4. 如果验收后 PR 发生改动，必须重新验收。
5. `FAIL` 或证据不足：不得合并，Codex 修复后重新提交。

鉴于 ChatGPT 当前的 GitHub 连接为只读，合并由 Codex 的已授权写入环境执行；ChatGPT 不声称已完成其无法执行的远端操作。
