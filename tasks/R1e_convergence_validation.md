# R1e — Sigma-Tiny 多 Epoch 收敛验证

已验收 R1d PR #5 的 Head `918225be2297c5e71453d91a38a6829a6e28a329` 保持不变，两项 CI 通过，已合入 main `f1733ae7c170b7c30e8792891dd39762bfc1047f`。R1e 以该版本为基。

严格从 R1d Epoch 1 最终 checkpoint 续训，完成 Epoch 2–3 后停点审计，满足条件才进入 Epoch 4–5。保持冻结的 1410 训练条目、79 内部验证图、seed 3407、FP32、microbatch 1、累积 8、恒定 AdamW lr 6e-5、原预处理及 668 参数张量分组。每轮 176 个八样本窗口和一个两样本尾窗，按实际有效像素数归一化。按内部总体 mIoU 保存独立 best.pt，同分保留较早轮次。
