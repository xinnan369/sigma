# R2k-Q1 — Thermal quality under an unseen synthetic degradation

Only original permitted R1g training images are read. Allocate complete R1f visual proxy groups into Quality Fit, Calibration and Holdout using seed 3407 and 256 group permutations. Choose the permutation minimizing day/night count imbalance relative to 60/20/20 using IDs and group counts alone. Author flips are audited by source identity and excluded from pixel reads. Never read official test, the historical 157 validation images, or semantic labels.

Use the six fixed 9×9 descriptors in the protocol. Each image is grayscale with the same 60×80 grid mapped to original pixels (x,y = 4 mod 8). Both Thermal and luminance RGB heads use identical descriptors, six affine weights and one bias, the same labeled positions, standardization and deterministic L-BFGS-B convergence cap. The ordinary L2 penalty is 0.001. Fit 64 points per available class per view with one healthy, one occluded and two Gaussian views. An independent permutation of fit labels trains the matched negative control. The perturbation mask is a synthetic location label for training and scoring; inference receives only the current image, fitted head and calibration.

Calibration reads a distinct set of groups under the same seen families. Select identity or affine logit recalibration by all-grid Brier, with listed order as the tie breaker. Quantize probabilities to 256 levels. Select the smallest threshold allowing at most 5% false alarms on healthy calibration views. Holdout uses healthy views and two unseen Gaussian-blur tiers. Blur the full image and paste within a random 96-pixel ROI. Each tier has an independent SHA256-derived stream and the kernel/sigma are frozen in the protocol. No blur pixels are read by fitting or calibration. Results concern synthetic damage and are not evidence of sensor malfunction or loss of semantic utility.

For Brier and AP use grid points from the two corrupted views, include both ROI and outside points, and report positive prevalence and balanced Brier with equal class weight. Healthy FPR uses separate intact images and explicitly reports the calibration-defined lowest gradient quintile. AUPRC is average precision on tied quantized bins. Other outcomes are AUROC, 10-bin ECE, calibrated reliability curves and operating-point recall. Stratify by D/N, blur strength, ROI-center quadrant, and deep interior after excluding the inner 12-pixel ring. Preserve all outside points in that last AP comparison. Each group contributes paired histogram counts. The 10,000 bootstrap draws resample whole groups with shared weights across estimators. Report row and group support and valid draws. No uncertainty is inferred from treating pixels as independent.

Pass requires AP paired lower bound above zero, favorable Brier point, healthy FPR no greater than 7%, low-texture FPR no greater than 10%, and positive AP differences in each D/N, interior and quadrant stratum. A lack of adequate group support gives INCONCLUSIVE; with sufficient support a clear negative AP result or any guardrail failure gives FAIL. An AP interval covering zero with the other guards passing gives INCONCLUSIVE. Balanced Brier and tier-level outcomes are diagnostics, not extra gates. Labels, fits, thresholds and execution SHAs must be frozen before final Holdout access.

Run with CUDA hidden and numerical libraries on one CPU thread. Keep learned coefficients, image data, calibration arrays and predictions local. Publish only source hashes, grouped results and non-image evidence. The independent verifier uses saved quantized predictions to check the inference contract, calibration, ROI, exposure phases, and the primary paired intervals. Stop after PR creation. No downstream GPU experiment is in scope.
