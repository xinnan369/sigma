# R2e — Selective Scan 因果路径分解

以 R2d 通过验收的五种子、三架构 Epoch 5 权重为实验对象。逐一核对 ledger、审计证书和权重 SHA256。验证沿用 R1g 的 157 张图、54 个视觉代理组与 R2a 的固定中心 Thermal 遮挡。先在 seed 3407 的三架构上运行同一组 12 张 pilot 图。

每个实际 CUDA 调用匹配模块名、调用序号、尺度和方向。分别复用 clean 或 corrupt 的状态更新输入 `(x, Δ, A, B)` 产生的状态轨迹、读出系数 `C`、直接输入项 `D*x`。完整二水平三因素组合包含三个单路径、三个双路径、全 clean 与全 corrupt。全图干预在 clean 输入上下文进行，对选定范围内各调用同时替换读出。在 SSM 上分别审查四个 CrossMamba 尺度、四个 ConcatMamba 尺度、编码器、解码器和全部扫描；CNN、Attention 的范围为共享 SSM 编码器、解码器和全部扫描。

Pilot 验证原始 CUDA 读出、分块末端状态与 R2b 参考轨迹的一致性，核对八个混合读出的参考值、原始预测哈希、Identity、扫描坐标和 Hook 清理。证书通过后才扩展到全量。主指标为 ROI 外新增、纠正、净错误和预测分歧，另报告距离带和全图 mIoU。统计使用 10,000 次种子与视觉组共享权重的配对 Bootstrap，辅以五个配对种子的 t 区间和符号。自然 corrupt 与 clean 上下文中的联合替换分别报告。

只归档元数据、路径统计、证书、日志及哈希。R2d 原权重以只读方式加载，官方 test 图像不进入评估。
