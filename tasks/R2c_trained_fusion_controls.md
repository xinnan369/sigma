# R2c — Sigma 非 SSM 融合公平对照与扰动传播归因

前置 R2b PR #10 的验收 Head 为 `1547e02cb887c8667efd8b011704a618629188b6`。核对 CI 和合并状态后合入 main `eb02e3c81fa727ce003240a5b59317c2cf01f69b`。

1. 运行原始 CrossMamba + ConcatMamba、R2b CNN 和 R2b Attention 三臂。只替换两组四尺度融合模块。公共编码器与解码器仍包含 SSM。三臂各从官方 VMamba-T 分类初始化独立构建，SSM 也重新训练。以公共参数和 buffers 的初始哈希、首个窗口三路输入哈希、逐窗口采样及增强随机状态核对可比性。
2. 固定 R1g 划分 1,254 条训练记录和 157 张验证图、seed 3407、FP32、单卡 microbatch 1、累积 8、恒定 AdamW lr 6e−5、原 CE 与预处理。每轮 156 个完整窗口与一个真实 6 样本尾窗，按有效像素归一化。每臂共五轮 785 次更新。所有可训练张量覆盖一次，独立存储 best/last 指纹，预先指定 Epoch 5 用于比较。
3. 三臂各完成 Epoch 1 后，独立审计初始化、梯度、采样、尾窗、优化器状态、验证及 checkpoint。三臂均通过才恢复 Epoch 2–5。继续阶段严格校验模型、优化器、调度器、采样与 RNG。
4. 所有 Epoch 5 都通过审计后，严格复现各臂逐图 clean 混淆矩阵，并执行冻结 R2a 预测级扰动。原始中心 64×64 遮挡为主条件，三个位置 Gaussian σ20 与三种种子、局部右移 dx8 为次要条件，另有 Identity。组间核对实际扰动输入指纹。模块输出替换和状态干预不属于本轮三臂比较。
5. 固定 54 个视觉代理组和 10,000 次配对重采样。主要指标为中心遮挡下的 ROI 外新增错误率与净错误率，均用所有有效外部像素作分母。报告绝对错误率、相对 clean 的净变化、纠正率、距离带、逐类、mIoU，以及共享抽样下 SSM–CNN、SSM–Attention 的 95% 区间。需要结合 clean 性能、参数量和计算量解读差异。

数据与 checkpoint 留在仓库外，不读取官方 test 图像。冻结训练计划见 [配置](../configs/R2c_protocol.json)，结果见 [报告](../reports/R2c_REPORT.md)。R2c PR 等待验收。
