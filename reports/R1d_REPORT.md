## 前景学习与剩余限制

类别 0 仍占大多数。其预测占比由 99.9260% 降至 92.6707%，接近内部验证真值的 92.3149%。car、person 和 bike 的 IoU 分别达到 80.3317%、68.8691% 和 39.5141%，说明一个 epoch 后已在内部验证中分出这些前景。guardrail、color cone、bump 的 IoU 仍均低于 0.04%。例如 color cone 仅预测了 11 个像素，虽然 Precision 为 100%，Recall 只有 0.0254%。

实际增强后训练有效像素中，类别 0 占 90.4972%，guardrail、color cone、bump 分别约占 0.1788%、0.1970%、0.2969%。按有效像素平均且没有类别权重的 CE 让稀有类贡献的像素项更少。沿用上游镜像、缩放、裁剪与 padding，忽略 255。本轮记录的是增强后类别计数，无法分离增强或像素分布各自的影响。学习率固定 6e-5，单轮单 seed 结果不支持判断其他学习率、训练时长或损失的效果。以上诊断没有用于改动训练协议。

官方 393 图 clean test、作者分割 checkpoint 复现、500 epoch 均为 **NOT RUN**。本轮只使用本地数据和 checkpoint，提交含代码、配置、指标与日志。R1d PR 等待验收。
