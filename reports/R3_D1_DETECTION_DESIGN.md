# R3-D1 — LLVIP 行人检测对照设计（冻结稿 v1，未训练）

R3-D1 只有设计和 NumPy 融合算子参考。必须等独立验收后另行批准训练。数据使用 R3-D0 的 9,926 Fit / 2,087 Validation / 12 Quarantine，文件及划分 SHA256 原样继承。只有代理分组，不能证明跨真实采集场景泛化。

| Arm | 输入与融合 |
|---|---|
| A RGB-only | RGB 单塔 |
| B Thermal-only | Thermal 单塔，灰度复制到三通道，便于使用相同单塔形状 |
| C RGB-T 普通卷积融合 | 双塔 + 因果 depthwise 三抽头 Conv1d |
| D RGB-T Mamba/SSM 融合 | 双塔 + 单状态对角线性 SSM；属于 SSM 机制对照，不等同于完整 Mamba 或 input-selective scan |

## 冻结架构

输入沿用 D0 无裁剪 640×640 letterbox、float32 /255。每塔使用五层 3×3 stride 2 padding 1 bias-free Conv、BN（eps 1e−5，momentum 0.1）、SiLU；通道依次 16/32/64/64/64。取 stride 8、16、32（80/40/20 网格）的三层特征。C/D 各位置将两塔拼接后以独立的 bias-free 1×1 Conv 128→64 投影，按 row-major 展平；每图每尺度归零（C 用两 token 零填充，不额外在行边界重置）。普通融合计算 y[t]=k0*x[t]+k1*x[t−1]+k2*x[t−2]；SSM 计算 h[t]=tanh(a)*h[t−1]+b*x[t]，y[t]=h[t]+d*x[t]。每尺度两个臂都有三个可训练 64 维向量，分别初始化 (d,a,b)=(1,0,0)、(k0,k1,k2)=(1,0,0)。A/B 在同一层直接送出特征。三尺度没有额外 neck；共用一个跨尺度检测头：一层 3×3 Conv 64→64 bias-free + 同配置 BN/SiLU，再接 1×1 Conv 64→5（带 bias），输出一类 person logit 和四个软正距离。

C/D 共享参数逐张量相同初始化：Conv 权重 Kaiming normal fan_in/ReLU、BN scale=1 和 bias=0、最终 Conv bias=0；对公共张量按规范化层名与 seed 派生初始化流，模态塔使用各自独立命名流。按中心落入框内赋正样本，半开边界；尺度由 sqrt(框面积) 分配，在 640 输入坐标以 <64、[64,128)、≥128 分别归 stride 8/16/32；重叠时较小面积优先，同面积按 XML 序。若不足一个正格点，选所分配尺度离框中心最近的格点，并限制回归只对中心在框内的格点（强制正例只监督分类）；与已有正格点冲突时保持原分配。四个偏移为 stride×softplus，回归 GIoU loss。分类使用 sigmoid focal BCE（α=.25, γ=2）；帧内分类与回归分别除以相应正例数（最小 1），两项权重 1，帧间等权。Padding 中心无监督、推理丢弃其预测；强制正例也仅选择有效中心。

## 优化、预算及评估闸门

Seed 3407 单训练种子，FP32、单设备、每个 batch 4 图。训练 10 轮，每轮将全部 9,926 条各遍历一次（2,481 个完整四图窗口 + 两图尾窗，共 2,482 次、10 轮 24,820 次更新，尾窗按实际图数平均）。每轮采样采用 NumPy PCG64 SeedSequence([3407,epoch])，0 起；随机翻转采用 SHA256("3407/<epoch>/<id>/flip") 首字节 <128。无其它增强、无预训练。AdamW lr=3e−4 恒定，betas .9/.999、eps 1e−8、weight decay .01 仅 Conv 权重；其余不衰减，无早停；失败即停止。每轮用同一干净 Validation，主要选择 COCO AP@[.50:.95] 最高，其次 AP50，再最早轮；无 Test 参与。

CPU 参考计数：融合新增每臂 25,152 参数和每帧 70,425,600 MAC 等效操作；投影计标准 MAC，三抽头包括 padding 操作，SSM 注入乘法单独折为 1 MAC 等效，tanh 每通道在扫描前计算一次并作为非 MAC 单列。共同架构的其他部分相同；独立实现后必须静态核对总参数差 ≤1%、总 MAC 差 ≤5%，并另列纯乘/加、tanh、BN/激活、内存与实测延迟。当前相等的是设计计数，不表示实际实现、吞吐或 GPU 成本已经验证；不允许虚假参数或靠验证精度改宽度。资源上限初始为单设备、四臂各 10 Epoch，若工程或资源预检不通过，不缩小协议后仍声称已完成正式比较。

冻结 evaluator 为 pycocotools 2.0.10 COCOeval bbox、类别 person ID=1、iscrowd=0、all area、IoU .50:.05:.95，101 个召回阈值、maxDets=[1,10,100]；无分数截断，以 sigmoid 降序（并列按 stride 8/16/32、行列顺序），IoU>0.65 抑制，保留 100 框。先逆变换并剪裁，删除零面积再做原网格 NMS；COCO 格式为 xywh。生产评价脚本和版本摘要必须在训练前锁定并做合成 parity 测试，本阶段不安装或运行正式 evaluator。延迟按 D0 的 FP32 batch 1、20 预热、100 同步测量；同运行环境分别报告模型与端到端中位/P95。参数量和 MAC 单独报告。

真实检测性能是未注入扰动的发布图像上评估的 AP50 与 AP50:95。合成鲁棒性是按 D0 固定 Thermal 退化条件分别计算这两项指标及相对 clean 的百分点变化，不能当作真实环境或传感器故障性能。合成衍生权限仍待确认，不生成真实图像退化。官方 test 需另获授权；同时报告完整 split 与去除历史 64 对的敏感性结果，不称完全盲测。
