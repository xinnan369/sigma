# R2j-A — R2i 门控失效机制分析

**结论。** 两个种子均未给出能同时超过原始 SSM、等容量 RGB-only 对照并保持 Clean 非劣性的证据。中心遮挡下，Gated 相对 SSM 的方向翻转主要对应原本就存在的 Clean 像素错误差异。增强轨道仍有小幅减少遮挡额外损伤的观察信号，现有证据无法将它归因于可校准的 Thermal 可靠性。

R2i-S2 [PR #19](https://github.com/xinnan369/sigma/pull/19) 验收 Head 为 `8b4cadebd40ac440a81adf18ae53659465d03854`，push/PR CI 2/2 通过，main 更新至 `953f5ecede41cccebb3c1f472440dadd4b48375d`。S1/S2 原始结果保持不变。本轮 GPU 推理、训练、新种子与官方 test 均为 **NOT RUN**。

## 证据与口径

CPU 逐行复核两种子、两训练轨道、三对照、四条件，共 7,536 条归档配对记录。逐样本对照冻结的 157 图与 54 组，核对类别及距离分解各自加总为全区域计数，并与 S2 独立审计的视觉组计数相等。Clean mIoU 差来自已核验的混淆矩阵摘要。所有新分层均为事后探索，使用 10,000 次视觉组配对重采样，同一抽样权重用于所有比较和分层。结果记录支持像素数、视觉组数、有定义的重采样次数及逐组原始计数。小类区间未做多重校正；视觉组是代理，采集时间独立性未知。[完整诊断及输入 SHA256](evidence/r2j-a/diagnostics.json)

## 六项机制判断

| 问题 | 已证实的观察或设计属性 | 与证据一致、仍需实验验证的解释 |
|---|---|---|
| 两种子为何翻转 | Clean 轨道中心差的跨种子变化为 +0.12835 pp，其中 +0.11676 pp 来自同 ROI 的 Clean 像素错误差。增强轨道中心差变动 +0.02907 pp，Clean 项变动 +0.03311 pp，DID 变化抵消约 0.00404 pp。 | 共享初始化与样本顺序的种子变化可能改变门控和主网络的联合优化。现有种子同时改变多条随机流，无法定位是哪一条，也无法从两个点估计跨种子稳定性。 |
| RGB-only 为何不一致 | RGB-only 对照与 Gated 有相同参数和评分算子，仍会重标定进入 Cross-Mamba 的两路特征。其 clean 轨道 3407/3408 的中心差分别为 −0.08339/+0.07469 pp，同 ROI 的 Clean 项为 −0.08697/+0.07303 pp。增强轨道差为 +0.03186/+0.05515 pp。 | RGB-only 评分可以学习场景、照度或语义代理，改善部分输入。当前数据无法区分代理信号、一般重标定与联合优化随机性。需要等预算错配评分图或冻结评分的干预。 |
| 增强为何无稳定优势 | 两个种子的增强轨道 Gated−SSM 主指标均未通过。该轨道的 DID 点估计均为负，3407 区间低于零，3408 跨零。Gated−Control 主指标两种子同为负，但 3408 区间及两种子累计区间跨零。 | 局部零值遮挡可能主要教会模型适应训练退化，未必给评分头一个可迁移的质量目标。结果也与增强令基线变得更接近或 Clean 代价盖过局部收益一致。固定评估下的两条轨道无法区分这些机制。 |
| Clean 能解释多少 | 如上表，在 Clean 轨道大部分翻转可由同 ROI 的 Clean 像素错误差作算术解释。增强 3408 的有利 DID 被不利 Clean 项盖过。 | 分解是同图同分母的恒等式。不能把 Clean mIoU 当作因果中介，不能推断提高 Clean mIoU 就一定能改善扰动指标。 |
| 16 参数是否不足 | 四尺度各用 3 权重加 1 偏置，给每个位置一个跨通道共享标量。三种归约、仿射分数和 tanh 无法显式表示邻域结构、通道特异置信度或方向依赖。同一标量强制两路一增一减。 | 表达上限可能约束鲁棒收益，但实验没有同信号的宽度消融。加宽也可能带来普通容量或优化收益，需要同算子同宽度的无 Thermal 信号对照。 |
| 分数是否可辨识 | 评分仅接收 RGB 绝对幅度、Thermal 能量与相邻通道乘积，训练只有分割 CE。输入能量与语义、传感完整性混合，评分正值增加 Thermal 的同时降低 RGB。八份本地 checkpoint 均通过 SHA256，并仅在 CPU 读取。3407 两轨 Gated 的四个跨通道项系数均为负；3408 各有一个正、三个负。 | 系数表明结构不是固定单调质量刻度，但不能测出实际激活、饱和或退化定位。需要独立质量目标、未见退化条件和错配图，验证控制住内容和昼夜后仍能识别退化。 |

## 异质性

- **昼夜。** Gated−SSM 的中心遮挡日间错误差从 3407 clean 的 −0.0237 pp 变为 3408 clean 的 +0.1706 pp；夜间分别为 −0.1413、−0.1016 pp。增强轨道日/夜分别为 +0.0222/−0.0422 pp 和 +0.0917/−0.0675 pp。这些是分层点估计，日夜代理不代表传感质量标签。
- **类别。** 3408 clean 的 Car 和 Person 分别少 13,636、6,380 个净错误；Background、Bike、Bump 分别多 21,208、10,454、20,033 个，抵消部分前景收益。Bump 仅由 6 组支持，Bike 由 17 组支持；大像素计数不等于独立重复。类别计数基于真实类，和预测分歧统计分开。
- **视觉组。** Clean 轨道 Gated−SSM 为 3407 的 31 组减少、23 组增加，对应 3408 的 11 组减少、43 组增加。变化不限于一个极端组。组方向按净像素计数，置信区间仍按组重采样后对像素计数汇总。
- **距离。** Clean 轨道 3407 各带均为负，3408 各带均为正。增强 3408 在 0–128 px 四带相加减少 6,813 个净错误，>128 px 增加 18,116 个，后者有更大分母。距离统计来自输出误差，不能据此确定内部状态路径或传播方向。

## 下一步边界

基于两种子结果，建议暂停沿用当前 16 参数门控的种子扩展。下一代优先验证独立校准的 Thermal 质量信号能否通过等预算与错配对照，再比较同一质量图作用于扫描写入或读出的效果。建议 Pilot 预算分别约 **0.60** 与上限 **0.25 GPU 小时**，均须独立验收，当前未执行。[研究选项、失败判据与预算](../docs/R2j_RESEARCH_OPTIONS.md)
