# R2i — 可靠性感知 RGB-T 融合

R2h PR #16 的验收 Head 与两项 CI 均匹配，main 仍处于原验收基线。已合并至 `78390978454698712720134f6c7e68df0289608c`。[R2h PR](https://github.com/xinnan369/sigma/pull/16)

R2i 假设、比较、Clean 非劣性边界、增强及 Pilot 预算在 GPU 运行前冻结。四尺度门控只使用真实 RGB/Thermal 特征。等容量对照改用 RGB 特征生成输入描述，保留同形状评分和两模态融合分支。两组各增加 16 个可训练参数，执行相同的门控运算。FLOPs 按门控运算约定统计，指数类算子调用单列，原模型 selective scan 的精确底层硬件 FLOPs 未测量。

每个训练策略包含三组，单组训练 24 条冻结训练记录。只使用内部验证像素，正式测试留待一次独立确认。历史使用过的 157 张内部图不能作为盲测。所有数值结果仅用于工程评估。

Windows 95 通过、4 跳过，WSL 99 通过。GPU Pilot 已通过。[预注册](../tasks/R2i_reliability_aware_fusion.md)

## 工程 Pilot

RTX 3090，PyTorch 2.2.2+cu121，FP32。六组各执行 3 次更新，共 18 次，训练窗口累计 66.71 秒，验证累计 753.42 秒。增强轨道每组有 16/24 条记录实际加入热红外遮挡。单组训练峰值为 6.87–6.92 GiB，合成输入推理中位延迟为 153.60–157.71 ms。进程级推理峰值为 0.57–1.15 GiB，包含同进程驻留分配，不能据此推断门控的边际显存。

三组共享参数初始化一致，初始完整模型 logits 逐位一致。基线覆盖 668 个参数张量，两种门控各覆盖 676 个。所有门控张量在每个窗口均有非零有限梯度。六组均核验首个 optimizer 更新后的模型 SHA、Torch CPU/CUDA RNG、采样状态和优化器恢复。该 Pilot 在同进程内验证重载，未模拟进程终止后自动续跑。

基线 48,287,360 参数，门控与控制分别为 48,287,376。两种门控按相同算子计数，各增加约 27.72M 标量操作，另有 25,500 次 tanh。该近似省略均值归约的除法，原始扫描算子未换算为精确 FLOPs。沿用 R2d 的 88.33G 基线 MACs 作为共享点积开销参考。

## 探索读数

所有六组 Clean 总体 mIoU 约 10.19%，前景 mIoU 约 0.034%。中心遮挡下，门控组相对同策略自然 SSM 基线的 ROI 外净错误变化，在无额外 Thermal 增强轨道为 −0.0000294 个百分点，视觉组 Bootstrap 95% CI [−0.0000957, +0.0000429]，在增强轨道为 −0.0000105 个百分点，区间 [−0.0000504, +0.0000367]。这些区间只反映单种子下的视觉组抽样。三窗口结果用于确认执行链，H1–H3 尚未完成正式检验。所有组、退化条件、距离带和类别结果均已归档。

工程闸门已通过，可在独立验收后进入五种子实验。按本次训练窗口线性外推，30 个训练单元各 785 次更新约需 24.25 GPU 小时。按本次验证耗时估计，最终轮次全条件评估另约 1.05 小时。若每轮均运行全条件评估，则验证约需 5.23 小时，另计持久化和审计。完整训练驱动需在正式阶段执行完整 epoch 与尾窗审计，当前 Pilot 仅跑固定的三个完整窗口。
