## 实际执行结果

所有阵列均在 NumPy 中生成，64×64，噪声种子 3407。合成标签只是构造说明，与传感器健康或任务效用无关。

| 反例 | 预期及实际检查 |
|---|---|
| 健康均匀 | 幅度为零；归一化卷积也保持不变，不能从无边缘直接断言故障或健康。 |
| 健康低对比度 | 梯度 RMS 0.125；与下方模糊观测逐像素相同。 |
| 健康高对比度 | 梯度 RMS 0.250，仅说明存在结构；是构造中的清晰参考。 |
| 模糊后的高对比度 | RMS 降为 0.125，单帧与对应健康低对比反例相同；相对真实构造参考 RMSE 0.08839。相同结果不允许解释为模型检测到模糊。 |
| 加性噪声 | RMS 升为 0.26832，说明增强幅度不等于信息更可靠。 |
| 局部遮挡 | 精确更改 1,024 点，其他像素不变；填充值可作证据，但单帧看不出是否是自然黑背景。 |
| 相位偏移的健康内容 | 像素布局不同，直方图与梯度 RMS 相同；幅度汇总无法区分。 |

对等先验的相同输入反例，强制单帧分类至少一半错误。全拒判在该反例上覆盖率为零、选择性风险未定义，不是零风险。构造只验证理论与实现边界，不构成 H2/H3 的效果证据。
