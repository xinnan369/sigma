# R2c — Sigma 非 SSM 融合公平对照与扰动传播归因

本轮比较原始 CrossMamba + ConcatMamba 与 R2b 定义的 CNN、Attention 融合层。三臂仅替换相同位置的融合模块，共用含 SSM 的编码器和解码器。R2b PR #10 的验收 Head `1547e02cb887c8667efd8b011704a618629188b6` 在核对两项 CI 和无冲突状态后合入 main `eb02e3c81fa727ce003240a5b59317c2cf01f69b`。[前置合并记录](evidence/r2c/prerequisite-merge.txt) · [冻结协议](../tasks/R2c_trained_fusion_controls.md)

## 训练和数据协议

上游 Sigma 固定在 `98ba3c6938d29169bbd27f91519084bb462561df`，VMamba-T 分类初始化 SHA256 为 `dbc0cc4f5ec0e45db5fba7c939d2c7d9b617e891ac10766912a8d604c37c5e47`。三臂均重新构建并训练。R1g 划分 SHA256 为 `4e6508427b401f055ce1878dd99cb2420c6e485a22f172e23d369448095d24c3`，包含 627 张训练原图及 627 张作者翻转、157 张验证图与 54 个视觉代理组。官方 test 仅核对 ID 隔离。GPU 训练预检核对了 4,233 个选定文件的 SHA256。[训练预检](evidence/r2c/training-preflight.json) · [配置](../configs/R2c_protocol.json)

训练固定 seed 3407、FP32、microbatch 1、梯度累积 8、恒定 AdamW lr 6e−5、betas (0.9, 0.999)、weight decay 0.01 并沿用原参数分组规则。沿用上游训练预处理、CE 与 ignore 255。每轮用相同排列遍历全部记录，执行 156 个八样本窗口及一个六样本尾窗，按各窗口真实有效像素归一化，共 157 次更新。构造完成后，在首个窗口前将三臂训练随机流统一重置为 3407，后续从各自 checkpoint 恢复 RNG。三臂公共参数和 buffers 初始状态逐键纳入指纹。首窗核对实际 GPU 张量，后续每窗核对记录 ID、数据增强前后 Python RNG、有效像素数和类别像素数。固定的上游随机翻转、缩放和裁剪由 Python RNG 驱动。

## 扰动和统计口径

Epoch 5 固定为主比较，即使其他 epoch 的内部验证分数更高。每臂先复现训练期间的 157 个逐图 clean 混淆矩阵，再运行 R2a 预测级 14 条件。包括中心 64×64 遮挡 fill 0、三位置三种 seed 的 Gaussian σ20、三位置局部右移 dx8，以及 Identity。扰动在归一化前作用于单通道 Thermal，固定 Boolean support、RGB、GT、模型和预处理。核对三臂每个样本每条件实际扰动输入 SHA256。ROI 外率的分母为有效外部像素，新增为 clean 正确而 corrupt 错误，纠正为反向转换，净增为两者之差。另报告相对 clean 的净变化 `(corrupt 错误−clean 错误)/clean 错误` 及以 clean 正确像素为分母的新增错误率。

主要对比预定为中心遮挡下 SSM–CNN、SSM–Attention 的 ROI 外新增和净错误率差。按冻结 54 个组重采样 10,000 次，seed 3407。每次抽样三个模型共享组权重，保留组内图像与 clean/corrupt 配对。总体和前景 IoU 从合并矩阵重新计算，缺失类别的 union 为零时在对应抽样中记为未定义。报告逐指标 95% percentile 区间。次要条件、距离带和逐类结果为探索比较。区间刻画固定 checkpoint 的视觉组抽样不确定性，训练种子只有一个。

### 计算量

使用 480×640 合成双模态前向，跟踪公共模块中的卷积与矩阵乘，按一次乘加记一 MAC。融合部分以实测尺度计算卷积、线性投影和注意力矩阵乘。另以实际 CUDA selective scan 的 batch、通道、长度和状态维度累计状态坐标更新数。逐元素 FLOP 与状态更新单独报告，不折算成 MAC。该统计覆盖指定运算，完整模型仍包括归一化、激活等其他运算。

| 融合 | 公共 GMAC/图 | 融合 GMAC/图 | 合计 GMAC/图 | 全模型 SSM 状态坐标更新/图 |
|---|---:|---:|---:|---:|
| SSM | 75.357 | 12.968 | 88.325 | 3,173,990,400 |
| CNN | 75.357 | 5.017 | 80.374 | 3,008,102,400 |
| Attention | 75.357 | 3.209 | 78.566 | 3,008,102,400 |

各臂公共路径实测 42 次 scan，公共路径另记录 353,436,288 次可计的逐元素 FLOP。CNN 和 Attention 的融合参数量、全模型参数量与运算量均低于 SSM，三臂匹配的是数据、训练更新预算及公共模块，容量不同。[计算量明细](evidence/r2c/compute-profile.json) · [GPU 记录](evidence/r2c/compute-profile-gpu.txt)

## 归因与证据边界

这批固定训练、划分和扰动下的结果**反驳了区域外传播需要 SSM 融合的假设**。CNN 在主条件的新增错误率更高，Attention 的新增率接近且预测分歧率更高。单看净错误会遗漏 Attention 中较多的错误纠正。三臂共享含 SSM 的编码器和解码器，传播可以经过公共模块，融合结构也可能改变传播幅度和新错与纠错的构成。

结论限于这三个融合实现、单种训练种子、五轮 checkpoint 和已有的内部验证集。参数量与计算量不匹配，无法单独分离融合算子形式、容量及学习到的权重对差异的贡献。区间刻画按视觉代理组重采样的误差，尚未估计跨训练种子的方差。R2b 的单时刻内部状态因果证据仍适用于其固定模型与位置，本轮未进行新的内部状态干预。
